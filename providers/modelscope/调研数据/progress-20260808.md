### 2. 费用规则（官方来源）
- 魔粒 = 用户所说的「魔力」（MagicCube），弹窗文案「预计魔粒扣减 X 魔粒/次」。
- **免费额度**：每日累计 2000 次免费 API 调用（UTC+8 0:00 重置，不跨日累计），超额返回 429；单模型约 500 次/天上限（部分模型更低）。
- **魔粒获取**：绑定阿里云后每日登录 +150 魔粒；每日任务最高 +250 魔粒/日；模型使用奖励最高 +200 魔粒/日。
- 官方文章：https://modelscope.cn/learn/1409 ；计费文档：https://modelscope.cn/docs/aigc/aigc-quota
- 魔粒价仅对**魔搭社区自营提供方**显示；第三方（百炼/智谱/Moonshot 等）走各自 Key 计费，弹窗不显示魔粒价。
- 观测规律：CostTier=ultra → 2 魔粒/次；standard → 1 魔粒/次。
