四、魔粒扣费规则（历版一致）

魔粒 = 用户所称「魔力」。按每次调用扣费（非按 token）：ultra = 2 魔粒/次，standard = 1 魔粒/次；魔搭社区自营提供方计价，第三方（百炼/智谱/Moonshot 等）走各自 API Key。每日累计 2000 次免费调用（UTC+8 0:00 重置，超额 429）；绑定阿里云每日登录 +150 魔粒，任务最高 +450/日——免费额度内实际支出为 0。
