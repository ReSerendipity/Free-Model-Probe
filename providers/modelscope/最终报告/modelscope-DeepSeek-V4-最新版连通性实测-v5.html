from openai import OpenAI

client = OpenAI(
    base_url="https://api-inference.modelscope.cn/v1",
    api_key="YOUR_MODELSCOPE_TOKEN"  # ms-xxx 格式
)

# === 方式 1: 使用 DeepSeek-V4-Pro 最新版 ===
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V4-Pro",  # 自动路由到最新版

        {"role": "user", "content": "写一个快速排序函数"}
    ],
    max_tokens=32768,
    temperature=1.0,
    extra_body={
        "reasoning_effort": "high"  # low/medium/high - 控制推理努力程度
    }
)

⚠️ 注意事项
  • 推理模型需要更大的 max_tokens —— DeepSeek/GLM/Step 系推理模型建议 max_tokens ≥ 1024，否则思考过程会被截断。
  • ModelScope 模型 ID 格式 —— 必须使用完整路径：组织/模型名，如 deepseek-ai/DeepSeek-V4-Pro，不能用简写。
  • 免费额度 —— 每日 2000 次免费调用（UTC+8 0:00 重置），绑定阿里云每日登录 +150 魔粒，任务最高 +450/日。
  • 重试策略 —— 遇到空响应（choices=null）或 429 时，退避重试 2~3 次，每次间隔 2 秒。
